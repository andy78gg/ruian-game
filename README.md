# Ruian Game

浏览器端生存游戏原型（Three.js）。参考 Roblox 生存建造类玩法，逐步搭建：地形、植被、昼夜循环、生存数值、建造/背包/合成、敌人与联机。

## 本地运行

ES Module + CDN 引入 Three.js，需要通过静态服务器打开（不能直接双击 file://）：

```bash
# 任选其一
npx serve .
# 或
python -m http.server 8000
```

然后访问 http://localhost:8000 。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标点击画面 | 锁定鼠标视角 |
| W / A / S / D | 移动 |
| Shift | 奔跑 |
| 空格 | 跳跃 |
| 1 – 7 | 切换快捷栏 |
| B | 进入 / 退出建造模式 |
| Q / E 或滚轮 | 切换建造构件 |
| F 或鼠标右键 | 进食（手持食物时） |
| 鼠标左键 | 攻击敌人 / 挥动 / 采集 / 放置 |
| 鼠标右键（建造模式） | 拆除已放置构件 |
| 鼠标 | 控制视角 |
