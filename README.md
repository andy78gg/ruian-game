# Ruian Game

浏览器端低多边形生存游戏原型（Three.js）。参考 Roblox 生存建造类玩法，逐步搭建：地形、植被、昼夜循环、生存数值、建造/背包/合成、敌人与联机。

## 本地运行

ES Module + CDN 引入 Three.js，需要通过静态服务器打开（不能直接双击 file://）：

```bash
# 任选其一
npx serve .
# 或
python -m http.server 8000
```

然后访问 http://localhost:8000 。

## 操作

| 按键 | 作用 |
| --- | --- |
| 鼠标点击画面 | 锁定鼠标视角 |
| W / A / S / D | 移动 |
| Shift | 奔跑 |
| 空格 | 跳跃 |
| 鼠标 | 控制视角 |
